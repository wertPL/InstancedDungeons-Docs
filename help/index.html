Diagnostic Workflow

  1. Validate the dungeon configuration and inspect any reported file/field errors:
CMD / TEXT
/dungeon validate <id>
/dungeon validate all
  1. Check active integrations (Vault, MythicMobs, ItemsAdder, Oraxen, Nexo, WorldGuard):
CMD / TEXT
/dungeon status
  1. Review the Troubleshooting guide and Complete Reference.
  2. When updating from an earlier release, follow the Updating checklist.
