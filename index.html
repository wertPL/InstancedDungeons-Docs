InstancedDungeons

InstancedDungeons runs isolated dungeon instances for solo players and parties on Paper servers. When a party starts a run, the plugin clones your configured template world into a temporary instance world, runs your stages, mob spawners, loot chests, and boss or trigger objectives, and deletes the temporary world when the run ends.

Getting Started Command Reference Dungeon Config

Quick Start

Create a template world, set spawn, exit, and objective points in editor mode, and validate before opening to players:

CMD / TEXT
/dg world create dragon_template flat normal 500
/dungeon create dragon_lair dragon_template boss
/dungeon edit dragon_lair
/dungeon setspawn
/dungeon setexit
/dungeon setboss
/dungeon save
/dungeon reload
/dungeon validate dragon_lair

Players can then open a party, invite members, and start an instance:

CMD / TEXT
/dungeon open dragon_lair
/dungeon join <code>
/dungeon start

Core Architecture

ComponentHow it works
Template WorldsCreate flat template worlds directly with /dg world create or use existing server worlds. Instances inherit gamerules, WorldBorder settings, and WorldGuard regions/flags.
ObjectivesComplete runs by defeating a configured boss (boss.yml) or activating a completion button/pressure plate (trigger.yml).
Stages and GatesLock sections of a dungeon behind block gates that open after clearing REGION, KILL_MOBS, LEVER, BUTTON, PRESSURE_PLATE, REQUIRED_KEY, TIME, SACRIFICE, MONEY_PAYMENT, or ITEM_PAYMENT missions.
Spawners and MobsTrigger Vanilla or MythicMobs pools on instance start or player proximity, with configurable delays and mob lifetime rules.
Loot and RewardsPlace tagged loot chests in the template world, distribute stage mission keys, and configure boss or trigger completion rewards.
TowersLink a FIRST entry dungeon to a LAST final dungeon so parties automatically progress between floors.
Event CommandsRun console or player commands on party creation, run start, stage completion, gate opening, mob/boss kills, completion, or failure.
ValidationRun `/dungeon validate <id
